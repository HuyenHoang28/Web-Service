# Web-Service

Bài tập HTML/CSS với khung bố cục Blakletterpress.

- `index.html`: trang chủ gốc.
- `register.html`: form đăng ký nhận thông tin (bài 3).
- `media.html`: trang đa phương tiện và semantic HTML5 (bài 4).
- `index_new.html`: trang chủ được refactor semantic HTML5 (bài 5).
- `PROMPT.md`: prompt refactor và ghi chú về dữ liệu minh họa.

## Cloudflare Pages

Kết nối repository này với Cloudflare Pages, chọn nhánh `main` và cấu hình:

- Framework preset: `None`.
- Build command: `exit 0`.
- Build output directory: `.`.
- Root directory: để trống.

Form chỉ xác thực dữ liệu, chưa gửi hoặc lưu dữ liệu trên máy chủ. Video, audio minh họa và bản đồ cần Internet.
