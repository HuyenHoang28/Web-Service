# Web-Service

Bài tập HTML/CSS với khung bố cục Blakletterpress. Trang chủ hiện là màn hình chọn hai bài thực hành tìm và sửa lỗi CSS:

- `Bai tap 1 Tim va sua loi CSS/`: sửa các lỗi box model và position làm vỡ bố cục.
- `Bai tap 2 Tim va sua loi CSS/`: sửa các lỗi tinh vi liên quan đến sticky, kích thước flex item và stacking order.
- `register.html`: form đăng ký nhận thông tin (bài 3).
- `media.html`: trang đa phương tiện và semantic HTML5 (bài 4).
- `index_new.html`: trang chủ cũ được refactor semantic HTML5 (bài 5).
- `PROMPT.md`: prompt refactor và ghi chú về dữ liệu minh họa.

## Cloudflare Pages

Kết nối repository này với Cloudflare Pages, chọn nhánh `main` và cấu hình:

- Framework preset: `None`.
- Build command: `exit 0`.
- Build output directory: `.`.
- Root directory: để trống.

Form chỉ xác thực dữ liệu, chưa gửi hoặc lưu dữ liệu trên máy chủ. Video, audio minh họa và bản đồ cần Internet.
